# WeDex 0.4.0

- Убрана подпись со списком сервисов под треками медиатеки и понравившихся.
- Вместо общей формы ключей — отдельные окна Яндекса, Last.fm, SoundCloud, Hitmo и YouTube Music. Открываются из списка источников и по логотипу сервиса. Стекло, темы и переходы 0,2 с сохранены.
- Яндекс: OAuth-токен и проверка аккаунта. Last.fm: API-ключ и проверка доступа к API. SoundCloud: OAuth access token и проверка поиска; работает и для токенов приложения, которым не требуется доступ к личному `/me`. YouTube Music: проверка поиска без выдуманного API-ключа.
- После вставки или изменения поля проверка запускается автоматически с задержкой 0,6 с после последнего ввода. Есть ручной повтор. Состояние и результат видны в окне выбранного сервиса. Ответ для предыдущего ключа или другого сервиса игнорируется. Проверка не сохраняет секреты; «Сохранить» изменяет только выбранный источник. Ошибки показываются общей фразой в этом окне и записываются в лог с маскированием проверяемого и сохранённых ключей.
- Hitmo: настраиваемый домен. Разрешён адрес сайта без путей, параметров и логина. Поиск продолжает использовать `/search?q=…`, страницы сохранённых песен — прежние пути и параметры на новом домене. Ссылки на внешние аудиофайлы не подменяются. Домен сохраняется между запусками и применяется к новым поискам и воспроизведению старых ссылок.
- Настройка предпочтения оригинальных версий перенесена из общей формы ключей в настройки приложения. Смена аккаунта Яндекса не применяет запоздавший импорт прежнего аккаунта.

Проверки: автоматическая проверка после вставки, отдельное сохранение, защита от старых ответов, редактирование полей на широком и компактном окне, сохранение домена и совместимость старых настроек. Локальный HTTP-тест проверяет неизменность маршрутов поиска и старой песни после смены домена. Живые проверки настроенного Яндекса и Last.fm прошли без воспроизведения аудио и изменения ключей.

Полный набор: 89 тестов прошли, 10 внешних проверок пропущены по умолчанию. Строгая проверка Clippy без предупреждений. Нативные снимки светлой и тёмной тем, включая окно 360×480, проверены отдельно.

Сборка: `dist/WeDex-0.4.0/WeDex-Sonora.exe`.
