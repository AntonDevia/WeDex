# WeDex 0.8.5

- VPS передаёт клиентам проверенный публичный адрес зеркала Hitmo.
- Приложение проверяет зеркало из своей сети, сохраняет рабочий старый адрес
  и меняет недоступный только после получения треков с нового.
- Новый домен синхронизируется обычным зашифрованным механизмом подключений.
- GitHub Actions проверяет зеркала каждый час; ошибка оставляет последнюю запись.

Сейчас известное зеркало — `https://ru.hitmox.net/`, проверенное с ПК.
**Автообнаружение через `hitmos.pro` пока не подтверждено:** InfinityFree
и GitHub получили HTTP 403. Обновление передаёт известный проверенный адрес,
но не гарантирует обнаружения следующего домена до устранения этого ограничения.
Подробности: [HITMO_MIRRORS.md](HITMO_MIRRORS.md).

Обновите ПК и телефон, затем нажмите обновление VPS в настройках WeDex.
