# WeDex 0.8.5

- VPS передаёт клиентам проверенный публичный адрес зеркала Hitmo.
- Приложение проверяет зеркало из своей сети, сохраняет рабочий старый адрес
  и меняет недоступный только после получения треков с нового.
- Новый домен синхронизируется обычным зашифрованным механизмом подключений.
- Google Apps Script находит новые зеркала через `hitmos.pro`.
- GitHub Actions проверяет кандидатов каждый час из двух российских сетей
  через Globalping; ошибка оставляет последнюю запись.
- Сохраняются альтернативы: найденное за рубежом зеркало не заменяет рабочий
  домен без проверки доступности из сети пользователя.

Рабочее зеркало — `https://ru.hitmox.net/`: проверено парсером WeDex и
российскими сетями, включая МТС. Google получил редирект на `.org`, но этот
кандидат не прошёл российские проверки, поэтому основным остался `.net`.
Подробности: [как устроена проверка зеркал](https://github.com/AntonDevia/WeDex/blob/v0.8.5/docs/HITMO_MIRRORS.md).

Обновите ПК и телефон, затем нажмите обновление VPS в настройках WeDex.
