# WeDex 0.3.2

- Удалена подсказка у иконки перезагрузки. Верхние кнопки Sonora остаются на своих местах.
- Полоска подключённых сервисов выровнена по левому краю с иконкой «Настройки» внизу меню.
- При каждом запуске Sonora показывает одну стеклянную кнопку в форме передней карточки трека: крупный Play, «Запустить Sonora», «По понравившимся». Оформление, скругления и пропорции взяты из карточки карусели.
- Нажатие начинает подбор по понравившимся, независимо от сохранённого в настройках предыдущего трека. Пока идёт загрузка, стартовая карточка показывает ожидание. Карусель появляется после получения рекомендаций, с переходом 0,2 с. Пустой ответ или ошибка оставляют возможность повторить запуск.
- Если понравившиеся ещё загружаются из Яндекса, нажатие ждёт завершения импорта. Сам импорт без нажатия музыку не запускает. Состояние старта не сохраняется между запусками приложения.

Сборка: `dist/WeDex-0.3.2/WeDex-Sonora.exe`.

Проверки: 82 теста прошли, 8 внешних проверок пропущены по умолчанию. Проверены стартовая карточка на широком и компактном окне, запрет повторного нажатия во время подбора, ожидание импорта, повтор после ошибки и переход к карусели. Строгая проверка Clippy без предупреждений. Нативные снимки обеих тем проверены отдельно.
