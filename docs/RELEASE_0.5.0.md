# WeDex 0.5.0 · локальное облако и пульт

Первый работающий вертикальный сценарий серверной части: запуск из приложения, привязка другого клиента, дистанционное управление плеером и синхронизация новых сессий прослушивания.

Добавлены Rust-пакет `wedex-cloud`, отдельный серверный бинарник, HTTPS/WebSocket, SQLite, одноразовые приглашения, ключи устройств и отзыв доступа. По умолчанию сервер доступен только на текущем ПК; домашняя сеть включается явно перед запуском. В настройках расположен раздел «Моё облако».

Браузерный пульт обслуживается сервером и использует локальные Medeo/Font Awesome. Он управляет выбранным ПК, отображает очередь, состояние и начальную статистику. Нативное Android-приложение ещё не готово.

Новые сессии учитывают продвижение проигрываемого трека, сохраняются локально и отправляются пакетами. Повторная отправка не удваивает минуты. Исторические минуты из старой краткой истории не восстанавливаются. Ограничения счётчика и TLS в домашней сети описаны в `LOCAL_CLOUD.md`.

Telegram-архив, файловая медиатека, SSH-установщик, Linux systemd-поставка и автоматические обновления сервера остаются следующими этапами. Для этой сборки VPS не требуется.

## Проверено

- `cargo test --workspace --locked --offline`: 98 успешных тестов, 10 существующих проверок с реальными сервисами/аудиоустройством пропущены.
- `cargo clippy --workspace --all-targets --locked --offline -- -D warnings` и `cargo fmt --all -- --check`: успешно.
- Release-сборки основного приложения и отдельного сервера: успешно.
- Настоящие TLS/WebSocket-соединения между независимыми тестовыми клиентами, команды, повтор Next, сохранность статистики после перезапуска, неправильный сертификат, отзыв ключа и блокировка второй службы на той же базе: успешно.
- Собранный `wedex-server.exe`: запуск в отдельном временном каталоге, HTTPS healthcheck с проверкой сертификата, выдача страницы пульта и встроенного Medeo: успешно.
- Нативная панель облака: визуальная проверка 1440×960 и 360×640; браузерная компоновка проверена на отдельной статической UI-фикстуре. Полный ручной сценарий на реальном телефоне и Linux-развёртывание не проверялись.
