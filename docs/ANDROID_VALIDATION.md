# Проверка Android 0.6.2 · 8 ноября 2026

Обновление 0.6.2: пульт перенесён в основной мобильный плеер. Обложка, состояние и очередь приходят с выбранного ПК, устройство выбирается в дзене, аппаратные кнопки меняют его громкость. В настройках телефона оставлено только подключение. Компоновка мини-плеера и дзена из 0.6.1 сохранена.

## Устройства

- Физический Nothing A059: Android 16, ARM64, экран 1080×2392, density 420. Обычный APK установлен и запущен. Для тестового аудио использовался отдельный пакет WeDex QA; после проверки он удалён.
- Эмулятор Pixel 7: Android 15 / API 35, x86_64, 1080×2400. Проверены портретная и горизонтальная ориентации.

## Выполнено

- Запуск и отрисовка Rust/egui/OpenGL ES, Medeo, Font Awesome, фон и стекло, навигация, поиск в публичном каталоге, ввод с Android-клавиатуры, кнопка отправки, прокрутка списка.
- Светлая/тёмная тема, настройки, отдельное окно подключения, отсутствие закрытия окна при фокусировке поля, мобильная кнопка вставки, системная кнопка «Назад».
- На физическом устройстве: настоящий CPAL/Oboe/rodio-декодер на сгенерированных PCM/WAV-потоках из локального HTTP-стенда; переход в фон с продвижением позиции; системные MediaSession-команды pause/play/next; дзен и эквалайзер.
- В эмуляторе: очередь из двух записей, подготовка следующего потока, автоматический переход в фоне и остановка в конце коллекции. Тестовые данные не включены в пользовательский APK.
- Настоящее соединение Android-клиента с локальным облаком через HTTPS/WSS с проверкой собственного сертификата. Привязка из окна приложения, отправка накопленной статистики, команды volume/pause/seek/next с подтверждением и проверкой опубликованного состояния.
- Регрессионный тест двух клиентов настоящего TLS-сервера: автоматический выбор играющего ПК, обложка и очередь в модели основного плеера, pause/volume/seek/like/equalizer/next и выбор собственного устройства. Локальная громкость и медиатека телефона при управлении ПК сохраняются. UI-тест проверяет выбор устройства из дзена и отсутствие пульта в мобильном окне подключения.
- На физическом Nothing A059 через изолированный WeDex QA: обложка тестового ПК в дзене, VolumeUp изменил опубликованную громкость ПК с 0.50 до 0.55; локальная мультимедийная громкость Android осталась 6/16. VolumeDown вернул 0.50; пауза, следующий трек, лайк и перемотка изменили состояние ПК. MediaSession переключился на REMOTE/ABSOLUTE и обратно на LOCAL после выбора «Этот телефон». Использованы собственный локальный TLS-сервер и синтетический издатель состояния ПК.
- Два инструментальных теста Android Keystore прошли на эмуляторе и на физическом телефоне: шифрование/повторное открытие/удаление/разные nonce и отказ от расшифровки изменённого GCM-сообщения. Использованы только синтетические ключи.
- Rust workspace: общая логика, очередь, рекомендации, поиск, текст, эквалайзер, пульт, статистика, TLS, повтор команд и сохранность базы. Отдельные регрессионные проверки мобильной навигации и отсутствия перекрытия Sonora с плеером в горизонтальном режиме.
- Строгий Clippy для Windows workspace и Android ARM64, Rustfmt. APK подписан, проверен `apksigner`; выравнивание архива проверено `zipalign -P 16`. LOAD-сегменты обеих Rust ELF-библиотек имеют выравнивание не менее 16 КБ.

## Что не проверялось сквозным тестом

Авторизованное прослушивание личных аккаунтов Яндекс Музыки/SoundCloud на телефоне, распознавание реальной песни через микрофон, Bluetooth-гарнитуры, телефонный звонок, длительная работа в Doze и все возможные прошивки. Для этих интеграций перенесён общий код, но проверка запуска APK не считается подтверждением их работы на каждом устройстве.

На тестовой сети Hitmo не ответил; ошибка обработана общим уведомлением и записью в журнал. Для проверки аудиодвижка использован локальный стенд, без подмены результатов в пользовательском приложении.

Минимальная поддерживаемая версия — API 26, однако реальное устройство с Android 8 отдельно не проверялось. Восстановление очереди после уничтожения процесса и продолжение работы после удаления задачи из списка недавних пока не реализованы. Ограничения облачного прототипа, каталогов и хранения описаны в ANDROID.md.

## Проверка 0.8.1 · 9 ноября 2026

На эмуляторе API 35 запущен APK с новым заголовком Sonora и окном обновлений. Android instrumentation: 3 теста — сохранение и целостность Keystore-записей, FileProvider установщика предоставляет доступ только к файлам внутри `files/updates`. Подпись APK совпадает с версией 0.6.2; `apksigner` и `zipalign -P 16` прошли. Регрессионный UI-тест проверяет открытие обновлений после прокрутки настроек. Физический телефон в этой сессии отсутствует в ADB.
