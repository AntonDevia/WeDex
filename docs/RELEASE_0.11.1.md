# WeDex 0.11.1

- Вернули обычную свободную прокрутку текста песни колесом мыши и пальцем. Текст больше не перескакивает по строкам, мелкие движения обрабатываются сразу.

- Во время ручного просмотра все строки остаются белыми и одного размера. Через три секунды без прокрутки возвращается текущая строка и её увеличение.

Обновление для Windows и Android. Обновлять VPS для этого изменения не нужно.
