# Автоматический адрес Hitmo

## Как это работает

1. Google Apps Script запрашивает `https://hitmos.pro/`, проходит цепочку
   HTTP-перенаправлений и проверяет поиск на найденном зеркале. Сервис запускается
   по запросу, кэширует результат на 10 минут и имеет только разрешение на внешние
   HTTP-запросы. Почта, файлы и ключи пользователей ему не доступны.
   Код: `deploy/hitmo-resolver/Code.gs`.
2. GitHub Actions каждый час получает результат и проверяет адреса через
   Globalping: два HTTPS-запроса поиска из российских сетей. В приоритете последнее
   рабочее зеркало. Новые домены добавляются в список альтернатив. Адрес публикуется
   только после успешной проверки обеих российских точек.
3. Результат находится в отдельной ветке:
   `https://raw.githubusercontent.com/AntonDevia/WeDex/hitmo-mirror/mirror.json`.
   VPS проверяет его раз в 15 минут и хранит последнюю запись рядом с базой.
4. Приложение получает адрес и альтернативы по защищённому соединению с VPS.
   Сначала проверяет текущий адрес из своей сети. Рабочий сохраняется; недоступный
   заменяется только после того, как новое зеркало вернуло треки.

При ошибке Google, Globalping или GitHub последний проверенный адрес остаётся
прежним. Клиенты могут использовать сохранённые альтернативы, проверяя их сами.
Это не гарантирует доступность у всех российских операторов: окончательная
проверка всегда происходит на устройстве пользователя. Произвольные домены
вне семейства Hitmo автоматически не меняются. Ручная смена домена во время
проверки имеет приоритет. Поиск зеркала идёт в фоне и не прерывает музыку.

Меняется только домен, пути сохранённых песен остаются прежними. После проверки
значение также попадает в существующую зашифрованную синхронизацию подключений.
VPS не получает ключ расшифровки. В публичной записи нет аккаунтов, API-ключей,
IP пользователей, файлов музыки и cookies. Globalping получает только публичное
имя зеркала и запрос `music`.

## Проверенный результат 14 ноября 2026

Google действительно получил `302` от `hitmos.pro` на `ru.hitmox.org` и проверил
его каталог. Однако `.org` не прошёл проверку из двух российских сетей, а
`ru.hitmox.net` вернул страницу поиска, в том числе из сети МТС. Поэтому основным
адресом выбран `.net`; `.org` хранится только как кандидат. На проверенном ПК
парсер WeDex получил 25 треков с `.net`.

InfinityFree и прямой запрос GitHub получили HTTP 403 от исходного сайта.
На InfinityFree оставлена отдельная диагностическая PHP-страница
`wedex-hitmo.infinityfreeapp.com`. Она не используется как API для VPS:
бесплатный хостинг требует браузерный JavaScript и cookies для входящих
запросов ([официальное объяснение](https://forum.infinityfree.com/t/why-isnt-api-access-working-on-my-website/115198)).
Защита хостинга не обходится. Переносимый PHP-вариант оставлен в
`deploy/hitmo-resolver/resolver.php` для обычного PHP-хостинга.

## Настройка своего проекта

- Создайте Apps Script, вставьте `Code.gs`, запустите `probeHitmo` и разрешите
  только «Подключение к внешнему сервису». Доступ к Drive и Gmail не требуется.
- Разверните как веб-приложение: запуск от владельца, доступ «Все».
  Оно принимает только фиксированный исходный адрес, входные URL не обрабатываются.
- Укажите публичный URL `/exec` в переменной GitHub `HITMO_RESOLVER_URL`.
  Это не секрет. Запустите workflow `Discover Hitmo mirror` для первой проверки.
- Для своего репозитория задайте `WEDEX_UPDATE_REPOSITORY` при сборке и
  `update_repo` в конфигурации VPS. Чтение публичного результата не требует
  учётной записи GitHub. Для Globalping в этой схеме также не нужен аккаунт.

Расписание: один запуск в час, обычно два теста Globalping и несколько запросов
Google. При недоступности основного адреса проверяются до пяти кандидатов;
ошибки квот оставляют старую запись. Программа и VPS не обращаются к Google
и Globalping за каждым треком — они читают маленькую запись из GitHub.

Обновите ПК, телефон и VPS до 0.8.5. Старые клиенты совместимы с обычной
синхронизацией подключений, но не умеют самостоятельно проверять новый список.

Документация сервисов:
[Google URL Fetch](https://developers.google.com/apps-script/reference/url-fetch/url-fetch-app),
[квоты Google](https://developers.google.com/apps-script/guides/services/quotas),
[Globalping API](https://globalping.io/docs/api.globalping.io).
