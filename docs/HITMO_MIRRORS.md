# Автоматический адрес Hitmo

VPS WeDex получает публичный адрес из
`https://raw.githubusercontent.com/AntonDevia/WeDex/hitmo-mirror/mirror.json`
раз в 15 минут. GitHub Actions пытается определить зеркало через
`https://hitmos.pro/` каждый час. Поддерживаются HTTP-редирект, meta refresh
и обычная ссылка с иностранной страницы на зеркало. Скрипты сайта не исполняются.

Перед публикацией PHP проверяет страницу поиска. При ошибке старый адрес
не заменяется; задача сообщает предупреждение. Последний результат хранится
в отдельной ветке `hitmo-mirror`, а на VPS — в `hitmo-mirror.json` рядом с базой.
В записи нет аккаунтов, API-ключей и данных пользователей.

Приложение получает адрес через защищённое соединение с VPS и проверяет поиск
из своей сети. Если старое зеркало ещё работает, оно сохраняется. Если старое
не работает, а новое возвращает треки, меняется только домен; пути сохранённых
песен остаются прежними. Проверка идёт в фоне, повторяется не чаще раза в 15 минут
для той же пары адресов и не прерывает музыку. Изменение вручную во время проверки
имеет приоритет. Произвольные пользовательские домены вне семейства Hitmo
автоматически не меняются.

После проверки новое значение также попадает в существующую зашифрованную
синхронизацию подключений. Сервер не получает ключ её расшифровки.
Для получения адреса из VPS нужен хотя бы один клиент версии 0.8.5 или новее;
рекомендуется обновить ПК, телефон и VPS. Старый VPS совместим с новым клиентом,
но сам адрес зеркала не передаёт.

## Фактическая доступность на 14 ноября 2026

На проверенном ПК `https://ru.hitmox.net/` возвращает страницу поиска.
InfinityFree получил пустой HTTP 403 от `hitmos.pro`. GitHub Actions получил
403 как от исходного домена, так и от запасного зеркала. Поэтому автоматическое
обнаружение нового домена из GitHub пока не подтверждено и может не работать.
Первый адрес публикуется отдельно после проверки с ПК; это не результат
успешного редиректа с GitHub. Если сайты начнут отвечать runner, задача сама
обновит запись. Если ограничение сохранится, потребуется другая точка проверки.

На InfinityFree создан отдельный сайт `wedex-hitmo.infinityfreeapp.com`
с диагностическим PHP-файлом. Он не используется как API для VPS:
бесплатный хостинг требует браузерный JavaScript и cookies для входящих
запросов ([объяснение администрации](https://forum.infinityfree.com/t/why-isnt-api-access-working-on-my-website/115198)).
Защита хостинга не обходится. Основной переносимый скрипт:
`deploy/hitmo-resolver/resolver.php` (PHP CLI или обычный PHP-хостинг с cURL и DOM).

Проверки: `php -l deploy/hitmo-resolver/resolver.php`,
`php deploy/hitmo-resolver/test.php`, тесты Rust и проверка реального каталога.
Скрипт принимает только исходный сайт и ссылки семейства Hitmo по HTTPS,
запрещает локальные IPv4-адреса, фиксирует DNS-адрес запроса,
ограничивает размер ответа и число переходов. Музыкальные файлы через GitHub
и InfinityFree не передаются и не хранятся.
