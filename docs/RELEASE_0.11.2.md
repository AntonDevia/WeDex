# WeDex 0.11.2

- Кнопка загрузки в медиатеке и понравившихся сразу скачивает понравившиеся треки на это устройство. Во время загрузки она превращается в кнопку отмены. Уже сохранённые файлы при отмене остаются.

- Убрано отдельное окно «Скачанное» и выбор ограничения 1/2/8 ГБ. У ручных загрузок больше нет ограничения общего объёма и количества в 2000 треков.

- В строках треков убраны названия сервисов. Сохранённые на устройстве треки отмечаются значком загрузки, в том числе на узком экране телефона.

- Автоматическое сохранение прослушанного и офлайн-режим перенесены непосредственно в настройки. Временный кэш хранится отдельно от защищённых ручных загрузок.

- Если на устройстве закончилось место, очередь останавливается. Загрузка и отмена не меняют текущую музыку.

Обновление для Windows и Android. Обновлять VPS для этих изменений не требуется.
