# WeDex 0.2.2

Исправлено закрытие «Подключений» при нажатии на поле API-ключа. Фон диалога и поля теперь перехватывают внутренний щелчок; закрытие по внешней области и крестику сохраняется. Над полями отображается текстовый курсор.

Регрессионный тест сначала воспроизвёл ошибку, затем проверил фокус и вставку вымышленных ключей во все три поля при размерах 1440×960 и 480×800. Ввод не отправляет ключи и не запускает сохранение. Проверяются также щелчки по свободной области панели и снаружи.
