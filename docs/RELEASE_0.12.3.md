# WeDex 0.12.3

- Android: удержание Backspace последовательно удаляет символы в строке поиска.
- В окне распознавания микрофон и кольца отцентрированы. Кольца реагируют на громкость и постепенно окрашиваются в фирменный зелёный. После записи появляется подпись «Ищем трек…».
- Android: системный плеер в шторке получает обложку текущего трека, в том числе из локального кэша.
- Android: возобновление с позиции паузы на Bluetooth-гарнитурах, которые отправляют команду паузы при обоих нажатиях.
