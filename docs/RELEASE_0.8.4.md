# Windows 0.8.4 · исправление SSH-мастера VPS

Исправлена ошибка `/bin/sh: 1: set: Illegal option -` при подключении и установке VPS. Windows checkout на GitHub преобразовывал встроенные `probe.sh` и `install.sh` в CRLF. В локальной сборке оставались LF, поэтому прежняя проверка не воспроизводила дефект опубликованного EXE.

Перед исполнением SSH-команды и передачей установочного скрипта окончания строк приводятся к LF. Бинарные данные передаются без преобразования. `.gitattributes` дополнительно закрепляет LF для `.sh` при сборке из Git на Windows.

На изолированной Debian 12 ВМ воспроизведена исходная ошибка. Затем исходные скрипты намеренно преобразованы в CRLF и встроены в настоящий Windows SSH-worker: прошли подключение к установленной VPS по root-паролю, подключение по SSH-ключу с паролем sudo и полная повторная установка. Идентичность сервера и устройства сохранены. В тестах добавлены CRLF-варианты обоих встроенных скриптов и выполнение скрипта с heredoc через настоящий `/bin/sh` в Linux CI.

Обновление относится к Windows-приложению. Сервер и Android остаются на 0.8.3. После установки Windows 0.8.4 повторите подключение в SSH-мастере.
