# WeDex 0.2.0

Выполнено: ваши пять логотипов сервисов, Font Awesome Free Solid во всех кнопках, Ambient на всех вкладках, центрированная подпись исходного трека Sonora, единые настройки, EQ ±12 дБ с предусилением и 18 пресетами, более заметное различие режимов рекомендаций, crossfade 0–12 секунд, LRCLIB, вертикальная громкость, дзен и закрытие в трей по умолчанию.

Проверки:

- `cargo fmt --check`, `cargo clippy --locked --all-targets -- -D warnings`.
- 67 автоматических тестов: очереди коллекций, сброс, выбор рекомендаций, аудиобуфер и HTTP resume, EQ/предусиление, плавные уровни, LRC, сохранение настроек, поздние ответы текста, управление панелями, клики дзена и текста, перетаскивание таймлайна, адаптивность 360×480–2560×1440, загрузка обложек и маски иконок для двух тем.
- Отдельно запущен тест native audio: два Sink на реальном аудиоустройстве при нулевой громкости, плавное затухание, пауза обоих потоков, Seek и Stop. Исходящий токен не отменяется раньше завершения перехода.
- Живой запрос LRCLIB: обычный текст и 40 синхронизированных строк. Полные тексты не сохранялись в отчёт; строки в UI fixtures придуманы.
- Нативное окно: открытие дзена щелчком по миниатюре, появление управления поверх обложки, выход по стрелке с восстановлением размера, переключение темы в настройках. Крестик скрыл тестовое окно; процесс продолжил работу. Возврат по физическому значку трея отдельно не проверялся.
- Отдельный нативный тест скрывает настоящее окно, посылает Show через очередь действий трея, проверяет восстановление и завершает через Quit. Скрытое окно продолжает обрабатывать события; Quit обходит настройку сворачивания.
- Визуально осмотрены настройки, EQ, Sonora, поиск, текст и дзен в светлой/тёмной теме и узкие панели 360×480. Исправлены обрезание подписи, чёрные SVG-маски в тёмной теме, обрезанный значок настроек и переносы текста.

Тексты доступны для записей, присутствующих в LRCLIB. При наличии LRC используются его таймкоды; при отсутствии синхронизации показывается обычный текст. Автоматический crossfade требует подготовленной следующей записи, иначе плеер переключается обычным способом. Переходы проверены на синтетическом аудио; сквозное длительное прослушивание всех внешних сервисов в этой версии не выполнялось.

Figma не изменялась. Релиз — папка `dist/WeDex-0.2.0`, без ZIP. Настройки и подключения совместимы с существующей локальной библиотекой.
