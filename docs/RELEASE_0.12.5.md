# WeDex 0.12.5

В «Медиатека → Импорт» можно перенести треки из Spotify, Яндекс Музыки и VK Музыки.

- Spotify принимает `Playlist*.json` и `YourLibrary.json` из архива данных аккаунта.
- Яндекс Музыка принимает ссылку на плейлист. Для подключённого аккаунта есть кнопка импорта понравившихся.
- VK Музыка принимает HTML со списком аудио из архива VK и выгруженный список треков.
- Для всех трёх источников подходят CSV с колонками названия и исполнителя, TXT и вставка текста в формате «Исполнитель — название».

WeDex ищет по названиям и исполнителям. Совпадения добавляются в «Понравившиеся», для ненайденных треков отображается список. При импорте передаются только метаданные.
