# WeDex 0.9.0

- Моя волна Яндекса — основной подбор Sonora; Last.fm остаётся резервным вариантом.
- Записи сначала берутся из локального кэша, затем ищутся на Hitmo с проверкой исполнителя, названия, версии и длительности. Если подходящая запись недоступна, используется исходный сервис.
- Офлайн-кэш с сохранением обложек, ручной загрузкой трека и понравившихся, лимитом места и отдельным разделом «Скачанное».
- Исходные треки Яндекса сохраняют свою принадлежность коллекции и ID для обратной связи Волне.
- Новое меню действий трека, свайпы плеера на Android, плавное открытие панелей за 0,2 с. Текст песни отображается только в дзене.
- Ограничен расход памяти на обложки; индекс скачанного обновляется в фоне по изменению данных. Отмена загрузки защищена от запоздалых результатов предыдущей попытки.

Настройки и медиатека сохраняются при обновлении. Сервер 0.9.0 сохраняет совместимость с текущим протоколом облака; музыка кэшируется на каждом устройстве отдельно.
