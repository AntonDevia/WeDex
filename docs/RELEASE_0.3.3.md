# WeDex 0.3.3

## Поиск

Раньше приложение сначала ждало треки и исполнителей Яндекса, затем запускало внешние каталоги и показывало всё только после завершения самого медленного запроса. Теперь треки Яндекса, исполнители и внешние источники запрашиваются одновременно. Каждый готовый ответ сразу появляется в интерфейсе. Поздние ответы дополняют результаты, дубликаты убираются; старый запрос не может подменить новый. Итоговый порядок источников и фильтры сохранены.

Живой замер на текущей сети: треки Яндекса — 386 мс, исполнители — 421 мс, YouTube — 618 мс. Один внешний источник завершился ошибкой через 24,6 с. Его ожидание больше не удерживает остальные результаты. Это измерение конкретного запуска, а не гарантия скорости сервиса.

## Лайв-текст

Колесо мыши над синхронизированным текстом включает ручной просмотр. Все строки становятся одинакового размера и полной яркости; текущая строка не увеличивается. Прокрутка не перематывает музыку. Через 3 секунды после последнего движения колеса возвращаются автопрокрутка к актуальной строке и её увеличение ×2. Размер, яркость и положение переходят за 0,2 с. Смена трека отменяет ручной режим. Реализовано для обычной панели и дзена; прокрутка обычного текста без таймкодов сохранена.

Проверки охватывают выдачу быстрого источника до завершения медленного, объединение частичных результатов, защиту от устаревших запросов и ручную прокрутку обоих вариантов текста с возвратом через 3 секунды. Живой тест поиска выполнялся без воспроизведения аудио.

Полный набор: 85 тестов прошли, 9 внешних проверок пропущены по умолчанию. Форматирование и строгая проверка Clippy прошли без предупреждений.

Сборка: `dist/WeDex-0.3.3/WeDex-Sonora.exe`.
