# WeDex 0.2.3

Исправлена подпись Sonora: режим подбора из понравившихся показывает только «Похоже на Вашу музыку». Режим подбора по выбранному треку показывает только «Подбор на основе [название трека]», название выделено полужирным. Подпись центрирована относительно области Sonora.

Режим определяется исходным выбором потока, а не метаданными очередной рекомендации. После «Сбросить» подпись возвращается к «Похоже на Вашу музыку».
