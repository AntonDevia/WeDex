# WeDex 0.10.0

- Плеер показывает загрузку и ожидание звука. Потерю сети теперь видно по значку подключения.

- Результаты поиска появляются постепенно. Во время ожидания список показывает заглушки будущих треков.

- Обложка следует за пальцем и показывает соседний трек. Плеер плавно разворачивается, а отменённые свайпы возвращаются на место.

- У списков появилась инерционная прокрутка. Исправлены пропуски быстрых касаний.

- Уменьшены задержки при открытии обложек и управлении музыкой на ПК.

- Описание обновления переносится по ширине и прокручивается. Кнопки установки остаются доступны под текстом. Описание установленной версии можно открыть без интернета.

- VPS можно обновлять с телефона. Браузерный пульт и отозванные устройства не получают доступа к обновлению.

Для первого перехода со старой версии сервера обновите VPS с ПК. После установки сервера 0.10.0 обновления доступны с уже подключённого телефона — подключать его заново не требуется.

Медиатека, подключения и настройки сохраняются.
