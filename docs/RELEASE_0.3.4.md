# WeDex 0.3.4

Ручная прокрутка лайв-текста стала построчной, без сглаживания и инерционного движения. Один шаг колеса переносит к соседней строке; несколько шагов — на соответствующее количество строк. Переносы внутри длинной строки учитываются как единый блок текста, поэтому остановка всегда приходится на целую строку. Мелкие движения точного колеса накапливаются до следующего шага.

Одинаковый размер и полная яркость текста во время ручного просмотра сохранены. Через 3 секунды без прокрутки возвращаются активная строка и автоматическое слежение. Возврат остаётся плавным, 0,2 с. Изменение применяется в панели текста и в дзене.

Проверки: немедленная фиксация строки в кадре ввода, отсутствие последующего движения, длинные строки с переносами, точное колесо, границы списка и возврат к текущей строке через 3 секунды.

Сборка: `dist/WeDex-0.3.4/WeDex-Sonora.exe`.
