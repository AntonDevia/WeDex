# WeDex 0.12.4

- В распознавании микрофон остаётся зелёным и неподвижным. Кольца реагируют на громкость, а по внешнему контуру идёт звуковая волна. Цвет заполняет кольца изнутри наружу.
- Медиатека открывается на вкладке «Понравившиеся». Убраны вкладка «Обзор», кнопки запуска всех понравившихся треков и пояснение о синхронизации коллекций.
- Очередь открывается на весь экран с текущего трека. Прослушанные и следующие треки доступны в общей прокрутке.
- На телефоне полноэкранный плеер можно свернуть свайпом вниз, в том числе с заголовка при открытом тексте песни.
