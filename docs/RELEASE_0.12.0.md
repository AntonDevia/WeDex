# WeDex 0.12.0

- Один VPS обслуживает независимые аккаунты: личные устройства, музыка, статистика и ключи сервисов.
- В «Моём облаке» доступны регистрация, вход и приглашения WeDex. Убраны локальный сервер, SSH-настройка, браузерные приглашения и встроенный пульт.
- Управление VPS перенесено в отдельное приложение WeDex Мастер для Windows. Только администратор может обновлять общий сервер.
- Прежняя личная база сохраняется и переносится в аккаунт с уже привязанного устройства.
- Локальные медиатеки и подключения разных аккаунтов разделены.
- Повторный вход сохраняет идентичность устройства и обновляет его токен.
- Публичный поиск Hitmo использует общий серверный кэш с резервным прямым поиском.
- Амбиентное свечение адаптируется к экрану телефона и стало ярче на обеих платформах, в светлой и тёмной темах.

Для этой версии сначала обновите сервер через WeDex Мастер. Старый сервер не поддерживает регистрацию аккаунтов.
