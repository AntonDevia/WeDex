# WeDex 0.11.0

- «Понравившиеся» синхронизируются между ПК и Android через своё облако WeDex. Музыкальные файлы не передаются.

- При первом подключении коллекции объединяются без дубликатов по идентификатору сервиса. Дальше передаются только изменения.

- Добавления и удаления работают без сети. Изменения сохраняются до подтверждения сервера и отправляются после восстановления связи.

- Удалённые песни не возвращаются со старого устройства или после повторного импорта Яндекса. При конфликте одновременного добавления и удаления приоритет получает удаление.

- В медиатеке появился значок состояния синхронизации: процесс, ожидание подключения или завершение.

- Импорт Яндекса пополняет общую коллекцию. Отсутствие трека в очередном импорте не удаляет его из общей медиатеки; удалить его можно снятием лайка в WeDex.

Для работы синхронизации обновите сервер VPS и приложения на устройствах до 0.11.0. Телефон и ПК должны быть подключены к одному облаку. Новая привязка не нужна.

Кэш и скачанные MP3 остаются отдельными на каждом устройстве. Пользовательские плейлисты и передача файлов в это обновление не входят.
