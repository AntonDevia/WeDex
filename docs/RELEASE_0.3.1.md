# WeDex 0.3.1

В Sonora вместо текстовой кнопки «Сбросить» — иконка перезагрузки Font Awesome. Она находится в одной строке слева от характера потока и очереди, имеет ту же область нажатия и плавный отклик 0,2 с. При наведении появляется подсказка «Сбросить поток». Действие сброса по-прежнему запускает новый подбор по понравившимся трекам.

Отдельная кнопка «Больше открытий» удалена. Выбор характера потока остаётся в его настройках.

Сборка: `dist/WeDex-0.3.1/WeDex-Sonora.exe`.
