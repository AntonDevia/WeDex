# WeDex 0.8.3 · проверка выпуска

Релиз: https://github.com/AntonDevia/WeDex/releases/tag/v0.8.3. Независимый сервер: https://github.com/AntonDevia/WeDex/releases/tag/server-v0.8.3.

## Что добавлено

- Предложения обновить Windows и Android из GitHub Releases, скачивание через API assets, проверка размера и SHA-256, установка по кнопке.
- Независимые обновления VPS с ПК владельца по HTTPS. Привилегированный systemd-обработчик проверяет релиз, сохраняет базу и проверяет запуск новой службы.
- Зашифрованная синхронизация токенов Яндекса и SoundCloud, ключа Last.fm и домена Hitmo; изменения без сети и отключение подключения. Импорт не открывает окно поверх плеера.
- Поддержка старой HTML-разметки Hitmo и новой Next.js/RSC. Позиция заголовка Sonora и отсутствие внутреннего обрезания боковых карточек на телефоне.
- Автоматические подписанные Android-сборки в Actions с прежним ключом подписи в закрытых Secrets.

## Выполненные проверки · 9 ноября 2026

- Rustfmt, строгий Clippy, 119 Rust-тестов workspace прошли; 11 дополнительных тестов, требующих внешнего окружения, по умолчанию пропущены. Отдельный живой тест нового Hitmo вернул 50 треков и проверил первые 8192 байта MP3.
- Настоящий TLS-обмен двух нативных клиентов: передача шифротекста, отсутствие токенов в базе сервера, запрет доступа браузерному пульту. На эмуляторе Android получены тестовый ключ Last.fm и домен Hitmo; ключ записан зашифрованным и удалён после удалённого отключения.
- На изолированной Debian 12 ВМ выполнены обновления 0.8.1 → 0.8.2 → 0.8.3 через настоящие релизы GitHub. Сохранены база, TLS-идентичность и устройства; повторный запрос возвращает `up_to_date`. На предрелизном стенде проверен возврат прежнего бинарника после неудачного запуска.
- Windows-обработчик проверен на отдельном EXE в пути с пробелами: отказ повреждённому файлу, замена, сохранение предыдущего файла и запуск новой версии. Действующее приложение пользователя не останавливалось.
- Android API 35: три instrumentation-теста Keystore и ограничения FileProvider папкой обновлений. Настоящее обновление 0.8.2 → 0.8.3 через интерфейс приложения: обнаружение релиза, загрузка, SHA-256, разрешение установки из WeDex, системное подтверждение, версия 803 и повторный запуск. Зашифрованный ключ устройства, целостность SQLite и домен Hitmo сохранились.
- APK проверен `apksigner` и `zipalign -P 16`; сертификат совпадает с ранее распространявшейся версией 0.6.2. EXE и APK из опубликованного релиза скачаны тем же загрузчиком с успешной проверкой SHA-256.
- GitHub Actions: проверки Windows/Linux и сборка всех трёх целей завершились успешно. Исходники проверены на токены и закрытые ключи перед публикацией.

Физический телефон в этой сессии не был виден через ADB; проверка Android выполнена на эмуляторе. Арендованная пользовательская VPS без её реквизитов не изменялась.

## Первый переход

Новую версию приложения установите вручную поверх прежней. Для VPS, установленной версией 0.7, один раз повторите SSH-мастер нового приложения. Для синхронизации подключений ранее привязанных клиентов создайте на ПК новое приглашение WeDex и импортируйте его на телефоне. Подробности: [UPDATES.md](UPDATES.md).
