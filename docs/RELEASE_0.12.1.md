# WeDex 0.12.1

- Android: уведомления приглушают музыку вместо короткой паузы. Собственное затухание и восстановление громкости занимают 0,2 секунды и не меняют выбранную громкость трека.
- Звонки и другие обязательные прерывания приостанавливают воспроизведение после затухания. Ручная пауза не отменяется возвращением аудиофокуса. Уведомления телефона не меняют звук управляемого ПК.
- Добавлены резервные шрифты Noto для китайского, японского, корейского, многих других письменностей, музыкальных/математических символов и монохромных эмодзи. Medeo остаётся основным шрифтом.
- Android: в настройках появилась кнопка «Поделиться журналом ошибок». Журнал ограничен по размеру, ключи скрываются перед записью и экспортом. Сохраняются также Rust-паники и сведения о необработанных Java-исключениях.

Сервер VPS и WeDex Мастер для этих исправлений обновлять не требуется.
