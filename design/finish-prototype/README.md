# Подключить переходы WeDex

Файл: https://www.figma.com/design/hh9WPK6OnPYis1tL7S0jDY?node-id=8-157

Переходы уже применены к живому файлу через собственный MCP и проверены чтением из Figma. `code.js` — дополнительный обычный локальный Figma-плагин для повторного применения того же плана связей к существующим слоям. Для обычного просмотра запускать его не требуется.

## Один запуск в Figma Desktop

Figma назначает ID новому плагину сама, поэтому сначала создайте его стандартным способом:

1. Откройте указанный файл в **Figma Desktop**.
2. Меню **Plugins → Development → New plugin**. Выберите **Figma Design**, задайте имя **WeDex — Connect Prototype** и вариант **Run once** / без интерфейса. Сохраните плагин в удобную отдельную папку.
3. Замените созданный Figma файл `code.js` на файл `code.js` из этой папки. Если созданный шаблон содержит `code.ts`, в его `manifest.json` поле `main` должно указывать на `code.js`; этот файл уже готов, Node.js и компиляция не нужны. Сохраните назначенный Figma `id` в манифесте.
4. В исходном макете запустите **Plugins → Development → WeDex — Connect Prototype**.
5. При успешной проверке появится уведомление с числом связанных элементов. Нажмите **Present**: начальным экраном станет Sonora.

Официальные инструкции: https://developers.figma.com/docs/plugins/plugin-quickstart-guide/

Если вы предпочитаете использовать существующий development-плагин, сохраните его манифест и ID, заменив только `code.js`. Шаблон manifest приведён ниже; `YOUR_FIGMA_ASSIGNED_PLUGIN_ID` необходимо заменить ID, который выдала Figma, его нельзя оставлять как есть.

```json
{
  "name": "WeDex — Connect Prototype",
  "id": "YOUR_FIGMA_ASSIGNED_PLUGIN_ID",
  "api": "1.0.0",
  "main": "code.js",
  "editorType": ["figma"],
  "documentAccess": "dynamic-page",
  "networkAccess": {"allowedDomains": ["none"]}
}
```

## Что применяется

- 422 элемента с реакциями, 374 перехода/действия с адресом назначения.
- Навигация Sonora / Поиск / Медиатека, шесть состояний треков, четыре плейлиста.
- Плавное листание карточек, предыдущий/следующий трек и стрелки клавиатуры.
- Очередь, эквалайзер, пресеты, настройка рекомендаций, источники, распознавание и выбор версии записи.
- Закрытие панелей кнопкой, кликом снаружи и Escape.
- Демонстрационное распознавание через 2,6 секунды; его можно отменить.
- Стартовая точка прототипа и фон презентации.

Компонентные play/pause, лайки, shuffle, громкость, ползунки и автоматический цикл фона уже записаны в Figma отдельно и не зависят от этого запуска.

Плагин использует обычный Figma Plugin API и не делает MCP-запросы. Он не получает OAuth-токены музыкальных сервисов, не обращается к сети, не создаёт новых экранов и не удаляет слои. Перед изменениями проверяются точные имена экранов и существование всех контролов и адресатов. При ошибке записи ранее изменённые реакции восстанавливаются. Повторный запуск применяет тот же план.

## Статус проверки

План проверен локально: все 30 экранов/панелей достижимы, неизвестных адресатов нет. Проверены завершение, отказ в другом файле, отказ при отсутствующем слое и откат после ошибки. Этот же план реально применён через локальный MCP-плагин в Figma Desktop; реакции прочитаны обратно и проверены. Отдельный одноразовый `code.js` проверен на модели Plugin API. Индивидуальные полосы EQ и выбор позиции шкал находятся в локальных интерактивных компонентах и повторно не создаются этим плагином.
